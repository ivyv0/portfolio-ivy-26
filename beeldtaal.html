The Social
Visual Language

A socially responsible poster campaign created for the course Beeldtaal, using semiotics, rhetoric and Gestalt principles to communicate a clear message to a specific target audience.

Context

For the course Beeldtaal, I created an ethically responsible poster for an awareness campaign. The assignment focused on using visual language to communicate a social message clearly and convincingly to a specific target audience.

The project was inspired by a visit to the Wereldmuseum in Amsterdam, including the exhibition Things That Matter. From this research, I chose a subject that could create awareness and translated it into a visual campaign concept.

Design Challenge

The poster had to speak for itself without extra explanation. This meant that every visual choice needed to support the message directly: the image, composition, typography, contrast, colour and hierarchy all had to work together.

Visual Theory

I applied three visual theories in the design process: semiotics, rhetoric and Gestalt. Semiotics helped me think about signs, symbols and meaning. Rhetoric was used to make the message more persuasive, while Gestalt principles helped structure the composition so the poster would be clear and visually strong.

Target Audience

The campaign was designed for a specific target audience, so the tone and visual style needed to match the people I wanted to reach. I focused on creating a message that felt direct, understandable and emotionally engaging.

Outcome

The final result is a poster campaign that communicates a social message through visual language. The design uses symbolism, contrast and composition to create awareness, while staying clear, ethical and visually convincing.
